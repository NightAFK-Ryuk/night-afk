# Night AFK - Private Bot Control Center

A Node.js web interface for managing isolated Mineflayer Minecraft bots.

## Features
- Multi-user isolation: Each user manages only their own bots.
- Admin Panel: Admin (Ryuk) approves users and views all global sessions.
- Interactive Web GUI & Inventory Clicker.
- SOCKS5 proxy support, target PVP, and auto-eat integration.

## Installation Instructions for Hosting
1. Node.js version 18 or higher is required.
2. Run `npm install` to install dependencies.
3. Run `npm start` (or `node server.js`) to launch the server on PORT 3000.
